# 💳 SmartBankPro

SmartBankPro, kullanıcıların kolayca hesap açabileceği, giriş yapabileceği ve işlemlerini yönetebileceği bir *banka simülasyonu* projesidir.  
Bu proje, JavaScript temellerini pekiştirmek amacıyla geliştirilmiştir.

---

## 🚀 Özellikler
- Yeni müşteri ekleme  
- Giriş yapma (isim + şifre ile)  
- Günlük işlem limiti tanımlama  
- Risk puanı ve işlem geçmişi yönetimi  
- Yanlış şifre girişlerinde hata mesajı

---

## 🧠 Kullanılan Teknolojiler
- *JavaScript (ES6)*  
- *Node.js ortamında test edilebilir yapı*  
- *Git & GitHub* versiyon kontrolü
